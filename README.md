# Vault Git Auto Sync

An Obsidian plugin for syncing a vault with a Git repository.

## Features

- Sync vault changes with a remote Git repository
- Run syncs manually or automatically on a schedule
- Pull and push changes from Obsidian
- Work with multiple Git branches
- Review and resolve sync conflicts

## Setup

Install the plugin in your Obsidian vault, then open its settings to configure the repository, branch, and sync options.

Always commit or back up important notes before resolving conflicts or switching branches.
